# XPWE <-> EXCEL Computing Converter

A tool to convert quantity survey files between **XPWE** (PriMus) and **Excel/XLSX** formats.

## Features
- **XPWE -> Excel Conversion**: Extracts data from PriMus into organized Excel sheets with categories and subtotals.
- **Excel -> XPWE Conversion**: Imports price lists or quantity surveys from Excel directly into PriMus.
- **Smart Mapping**: Graphical interface to map Excel columns to PriMus fields, resolving naming ambiguities.
- **Support for Simple Surveys**: Handles Excel files with total quantities or with measurement details (N, Length, Width, Height).
- **Modern Design**: Intuitive and fast graphical interface.

## Getting Started

### Using the Executable (Recommended)
1. Go to the `dist` folder.
2. Run `xpwe_converter_app.exe`.
3. Python is not required.

### Using Source Code
To run the software via Python:
1. Ensure Python 3.10+ is installed.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the app: `python xpwe_converter_app.py`.
